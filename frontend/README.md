# THREADLINE frontend

Next.js 16 App Router frontend for the THREADLINE synthetic decision-support demo.

From this directory:

```powershell
npm install
npm run dev
```

Mock mode is the default. Set `NEXT_PUBLIC_API_URL` only to connect the canonical `POST /api/v1/analyze` endpoint. Full setup, safety positioning, demo steps, and validation commands are documented in the repository root `README.md` and `docs/frontend-architecture.md`.
